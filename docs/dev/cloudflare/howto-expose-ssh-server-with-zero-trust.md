# Cloudflare - Howto - Expose SSH server with Zero Trust
## Howto Goal


GOAL: Utilize Cloudflare Zero Trust to securely expose your SSH server to the Internet without the need to open inbound ports. This approach replaces traditional SSH keys with short-lived certificates, issued based on the token generated by users' Access logins, enhancing security and eliminating the management of long-lived SSH keys.

> [!REFERENCE] Official Guide: [Expose SSH server with Zero Trust](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/use-cases/ssh/)

> [!IMPORTANT] Among the different approaches to expose your SSH server with Zero Trust, this guide follows a specific approach: "SSH with Access for Infrastructure" (recommended by Cloudflare as of november 2024).

### SSH Infrastructure Access




[Access for Infrastructure](https://developers.cloudflare.com/cloudflare-one/applications/non-http/infrastructure-apps/) uses the same deployment model as [WARP-to-Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/use-cases/ssh/ssh-warp-to-tunnel/) but unlocks more granular policy options and command logging functionality.
